# tromino-puzzle-algorithm
This repository implements an algorithm for solving a Tromino Puzzle. The puzzle includes a 2^m-by-2^m grid (m is a positive integer) and L-shaped pieces (trominos) made of three units. The goal is to fill the grid with trominos without covering the missing square.
